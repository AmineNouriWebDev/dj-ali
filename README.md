# 🎧 DJ Ali — Site Vitrine Officiel

Site vitrine One-Page immersif et haut de gamme conçu pour **DJ Ali**, spécialiste de l'animation de mariages orientaux, mixtes et événements d'exception en Nouvelle-Aquitaine et France entière.

---

## 🌟 Points Forts & Fonctionnalités

- **Thème Sombre & Ambiance Clubbing/Événementiel** : Esthétique soignée, typographies premium (Cinzel Decorative / Outfit), effets néons et dorés.
- **Hero Section Immersive** : Audio-visualizer interactif en Canvas, typographie dynamique, call-to-actions rapides (Devis & Démo).
- **Lecteur Audio Intégré & Mixes** : Extraits audios avec player interactif et playlist par ambiance (Chaâbi, Raï, Reggada, Oriental Pop, Deep House).
- **Galerie & Événements Vidéo** : Showreel et ambiances live en modale interactive.
- **Calculateur de Devis / Formulaire Intelligent** : Formulaire multi-étapes interactif avec estimation en direct et choix des options (Pack Sonorisation, Robot LED, Fumée lourde, Percussions, etc.).
- **Témoignages & Avis Clients** : Retours d'expérience et notes vérifiées des mariés.
- **Section FAQ Interactive** : Accordéons fluides pour répondre aux questions fréquentes des futurs mariés.
- **Accès Direct WhatsApp & Téléphone** : Boutons de contact instantanés pour un taux de conversion maximal.

---

## 🛠️ Stack Technique

- **Structure** : HTML5 sémantique
- **Styling** : Tailwind CSS (CDN optimisé) + CSS Vanilla sur-mesure (animations néon, glassmorphism)
- **Animations & Interactivité** : Vanilla JavaScript, Lucide Icons, Canvas API pour le visualiseur audio

---

## 🚀 Déploiement / Utilisation Locale

Ouvrez simplement le fichier `index.html` dans n'importe quel navigateur moderne ou servez-le via un serveur statique :

```bash
# Avec npx serve ou Live Server :
npx serve .
```
